# Excel Masters Community Configuration & Profile 📊

This repository hosts the organization-wide configuration, GitHub Actions automation, community health files, and the official profile landing page for **[Excel Masters](https://github.com/ExcelMasters-in)**.

## 📁 Repository Structure

- `profile/README.md`: The official profile landing page displayed on [github.com/ExcelMasters-in](https://github.com/ExcelMasters-in).
- `profile/assets/`: Brand assets, icons, and logos.
- `.github/workflows/`:
  - `ci.yml`: Continuous integration validating organization assets and documentation integrity.
  - `community-bot.yml`: Smart auto-triage, lead maintainer assignment, and welcome responses for incoming issues and pull requests.
- `.github/ISSUE_TEMPLATE/`: Standardized, user-friendly forms for bug reports and feature requests.
- `.github/pull_request_template.md`: Contributor checklist and PR template.
- `.github/CONTRIBUTING.md`: Contribution guidelines for community members.
- `.github/SECURITY.md`: Vulnerability disclosure policy.
